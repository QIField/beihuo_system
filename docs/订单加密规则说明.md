# FSBBR 订单查询 - 客户对接说明

## 1. 概述

客户系统使用我方提供的密钥，将订单号加密后拼接成 URL，用户扫码或点击链接即可查看订单物流信息。

```
客户系统
    │
    ├── 订单号 + 密钥 → 加密字符串
    ├── 拼接 URL：https://x.fsbbr.net/order/view?no=加密字符串
    └── 生成二维码或直接提供链接
              │
              ▼
        用户扫码/点击访问
              │
              ▼
        我方解密并展示订单页面
```

## 2. 加密算法

| 项目 | 说明 |
|---|---|
| 算法 | Fernet（AES-128-CBC 加密 + HMAC-SHA256 签名） |
| PHP 库 | `kelvinmo/fernet-php`，安装：`composer require kelvinmo/fernet-php` |
| 密钥 | 44 位 URL-safe Base64 字符串，线下交付 |
| 输入 | 明文订单号，如 `XSDD002202609090313` |
| 输出 | URL-safe Base64 密文，可直接作为 URL 参数 |

密文特点：
- 同一订单号每次加密结果不同，但都有效
- 密文被篡改任意一位，解密都会失败
- 密文长期有效，不设过期时间

## 3. PHP 加密示例

```php
<?php
require 'vendor/autoload.php';

use Fernet\Fernet;

// 我方线下交付的密钥
$key = 'xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx=';
$fernet = new Fernet($key);

// 明文订单号
$orderNo = 'XSDD002202609090313';

// 加密
$cipher = $fernet->encode($orderNo);
```

## 4. URL 拼接

```php
$url = 'https://x.fsbbr.net/order/view?' . http_build_query(['no' => $cipher]);
// 示例：https://x.fsbbr.net/order/view?no=gAAAAAB...
```


## 5. 生成二维码

二维码内容即为上一步的 URL。PHP 示例（`endroid/qr-code`）：

```php
<?php
require 'vendor/autoload.php';

use Endroid\QrCode\QrCode;

$qrCode = QrCode::create($url);
header('Content-Type: ' . $qrCode->getContentType());
echo $qrCode->writeString();
```

安装依赖：`composer require endroid/qr-code`

## 6. 页面展示内容

访问链接后展示：
- 订单号
- 物流单号（如有）
- 经手人（如有）
- 物流进度：已下单 → 仓库已接单 → 已出库
- 发货照片（如有）

## 7. 异常处理

| 场景 | 页面表现 |
|---|---|
| 密文错误/密钥不一致 | 显示"未找到订单信息" |
| 订单不存在 | 显示"未找到订单信息" |
| 订单尚未发货 | 只显示"已下单"或"仓库已接单" |

## 8. 注意事项

1. **密钥请妥善保管**，不要写死在前端代码、不要提交到公开仓库
2. 生产环境和测试环境应使用**不同的密钥**
3. 密钥泄露或需要更换时，需双方约定时间同步切换，切换后旧密文全部失效
4. 建议对 URL 中的密文做 URL 编码，避免特殊字符导致的问题

## 9. 完整 PHP 示例

```php
<?php
require 'vendor/autoload.php';

use Fernet\Fernet;
use Endroid\QrCode\QrCode;

$key = 'xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx=';
$fernet = new Fernet($key);

$orderNo = 'XSDD002202609090313';
$cipher = $fernet->encode($orderNo);

$url = 'https://x.fsbbr.net/order/view?' . http_build_query(['no' => $cipher]);

// 生成二维码
$qrCode = QrCode::create($url);
$qrCode->writeFile(__DIR__ . '/order_qrcode.png');

echo "链接：$url\n";
echo "二维码已保存到 order_qrcode.png\n";
```
