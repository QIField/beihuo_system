# 订单信息查询 - 对接说明（加密规则）

> 本文档提供给对接客户使用。我方系统已按本规则实现解密，请贵方按同样规则加密订单号后拼接 URL、生成二维码。

## 1. 业务流程

```
客户系统                                我方系统                    终端用户
   │  按规则加密订单号                      │                         │
   │  拼接 URL ──────────────────────►   /order/view?no=密文        │
   │  用 URL 生成二维码 ─────────────────────────────────────────► 扫码访问
   │                                     │ 解密 → 查库 → 返回页面    │
```

## 2. 加密算法

| 项目 | 说明 |
|---|---|
| 算法 | Fernet（AES-128-CBC 加密 + HMAC-SHA256 签名），跨语言规范，各语言均有实现 |
| PHP 实现库 | `kelvinmo/fernet-php`，安装：`composer require kelvinmo/fernet-php`（要求 PHP 7.0+，仅需 openssl 扩展） |
| Python 实现库 | `cryptography`，安装：`pip install cryptography`（我方使用） |
| 密钥 | 双方线下交付，格式为 44 位 URL-safe Base64 字符串 |
| 密文特点 | URL 安全，可直接作为 URL 参数；同一订单号每次加密结果不同，但均有效；密文被篡改任意一位解密都会失败 |

## 3. 加密示例代码（PHP）

```php
<?php
require 'vendor/autoload.php';

use Fernet\Fernet;

$key    = 'xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx=';  // 线下交付的密钥
$fernet = new Fernet($key);

$orderNo = 'DD20260903001';                            // 明文订单号
$cipher  = $fernet->encode($orderNo);                  // 密文，如 gAAAAABl...
```

安装依赖：`composer require kelvinmo/fernet-php`

### Python 参考实现（与我方一致，用于自测）

```python
from cryptography.fernet import Fernet

fernet = Fernet(KEY.encode())
cipher = fernet.encrypt(order_no.encode("utf-8")).decode("ascii")
```

## 4. URL 拼接规则

```
https://x.fsbbr.net/order/view?no=<加密后的订单号>
```

> 域名以实际交付为准。拼接时建议对密文做 URL 编码（PHP 示例）：

```php
$url = 'https://x.fsbbr.net/order/view?' . http_build_query(['no' => $cipher]);
```

## 5. 生成二维码（可选）

二维码内容就是第 4 步的 URL，可用任意二维码工具生成。PHP 示例（`endroid/qr-code`）：

```php
<?php
require 'vendor/autoload.php';

use Endroid\QrCode\QrCode;

$qrCode = QrCode::create($url);
header('Content-Type: ' . $qrCode->getContentType());
echo $qrCode->writeString();   // 直接输出 PNG 图片
```

安装依赖：`composer require endroid/qr-code`

## 6. 页面效果与异常

- 解密成功且订单存在：展示订单信息页面（显示当前物流状态：已下单 / 仓库已接单 / 已出库）
- 链接无效（密文被篡改、密钥不一致）、订单不存在：展示"未找到订单信息"提示页

## 7. 注意事项

1. 密钥请妥善保管，勿提交代码仓库或下发前端
2. 密钥更换需双方约定时间同步切换，切换后旧密文全部失效
3. Fernet 密文自带时间戳但不设过期时间，链接长期有效；如需限时链接请与我方联系调整方案
