# 开思券对账

> 独立脚本，只比对**开思券账单**与**开思电子对账单**，输出带`状态`列的Excel。  
> 基于脚本：
> - [tests/script/reconciliation/create_excel.py](file:///e:/Barbori/complete_project/beihuo_system/tests/script/reconciliation/create_excel.py)
> - [tests/script/reconciliation/ks_process.py](file:///e:/Barbori/complete_project/beihuo_system/tests/script/reconciliation/ks_process.py)
> - [tests/script/reconciliation/payment_bill.py](file:///e:/Barbori/complete_project/beihuo_system/tests/script/reconciliation/payment_bill.py)
> - 字段来源：[demo/t1](file:///e:/Barbori/complete_project/beihuo_system/demo/t1)

---

## 1. 功能定位

- 独立对账脚本，不写入金蝶。
- 输入 2 个 Excel：
  1. **开思券账单**（demo/t1）
  2. **开思电子对账单**
- 按订单号关联，核对券金额、平台已结算金额是否一致。
- 输出一列 `状态`：一致写“正常”，不一致写具体问题。

---

## 2. 输入数据

| 文件 | 关键列 |
| --- | --- |
| 开思券账单 | `订单/退货单号`、`交易金额(￥)`、`应收金额(￥)`、`开思券税率`、`调整原因` |
| 开思电子对账单 | `订单/退货编号`、`客户代码`、`对账金额(¥)`、`开思劵(¥)`、`平台已结算金额（¥）`、`价税合计` |

---

## 3. 计算公式

```text
rate = float(开思券税率.replace("%", "")) / 100

if rate > 0 and 应收金额(￥) > 0:
    开思劵_券账单 = 应收金额(￥) / rate
else:
    开思劵_券账单 = 0

对账金额_券账单 = 交易金额(￥) - 开思劵_券账单
```

---

## 4. 处理流程

1. **读取开思券账单**
   - `header=0`。
   - 清洗金额：去掉 `¥`、逗号、空格。
   - 解析税率：`"4.0%" → 0.04`，空/非法按 0。
   - 规范订单号：退货单取 `(` 之前的单号。
   - 计算 `开思劵_券账单`、`对账金额_券账单`。

2. **读取开思电子对账单**
   - 同现有 `ks_process.py` 逻辑。
   - 规范订单号，与券账单口径一致。

3. **按订单号关联**
   - 以券账单为左表，左连接电子对账单。

4. **生成状态列**
   - 逐项校验，有任意一项不符就写入具体原因；全部通过写“正常”。

---

## 5. 状态规则

| 校验项 | 状态文本 | 判断条件 |
| --- | --- | --- |
| 电子对账单缺失 | `电子对账单无此订单` | 订单号在券账单有、电子对账单无 |
| 券金额不一致 | `券金额不一致` | `abs(开思劵_券账单 - 开思劵_电子对账单) > 0.01` |
| 平台已结算金额不一致 | `平台已结算金额不一致` | `abs(平台已结算金额_电子对账单 - 交易金额(￥)) > 0.01` |
| 券账单金额不平衡 | `券账单金额不平衡` | `abs(对账金额_券账单 + 开思劵_券账单 - 交易金额(￥)) > 0.01` |
| 税率解析失败 | `税率解析失败` | `开思券税率` 非空但无法解析 |
| 调整原因非空 | `有调整原因` | `调整原因` 非空（仅提示，不覆盖其他状态） |
| 全部通过 | `正常` | 以上均无 |

> 优先级：电子对账单缺失 > 税率解析失败 > 券账单金额不平衡 > 券金额不一致 > 平台已结算金额不一致 > 有调整原因 > 正常。  
> `有调整原因` 可单独作为一列 `调整原因` 输出，不直接覆盖`状态`。

---

## 6. 输出 Excel

一个文件，建议包含以下 sheet：

| Sheet | 内容 |
| --- | --- |
| `开思券对账` | 关联结果 + `状态`列 + 券账单/电子对账单关键字段并列 |
| `异常` | 状态不是“正常”的行 |
| `开思券账单` | 原始数据 + 计算列 |
| `开思电子对账单` | 原始数据（供参考） |
