# 汽车配件库 Excel/CSV 文件上传设计方案

## 一、功能概述

在汽车配件库列表页面添加批量导入功能，支持 Excel（.xlsx, .xls）和 CSV 格式文件上传，实现配件数据的批量导入。

## 五、后端设计

### 5.1 API 接口设计

#### 5.1.1 文件上传接口
```
POST /new/api/car-parts/import
```

**请求参数：**
- `file`: 文件对象（multipart/form-data）
- `mode`: 导入模式，可选值：
  - `upsert`: 存在则更新，不存在则插入（默认）
  - `insert`: 仅插入新数据，重复则报错

**响应格式：**
```json
{
    "code": 200,
    "msg": "导入成功，共处理 100 条数据，成功 95 条，失败 5 条",
    "data": {
        "total": 100,
        "success": 95,
        "failed": 5,
        "errors": [
            {
                "row": 3,
                "part_number": "123456",
                "error": "配件编号已存在"
            }
        ]
    }
}
```

### 5.2 服务层设计

#### 5.2.1 Excel 处理服务（excel_import_service.py）

**核心功能：**
1. 流式读取文件（不加载整个文件到内存）
2. 验证列名
3. 逐行验证数据
4. 数据类型转换
5. 批量保存

**流式读取方案：**

对于 Excel 文件，使用 `openpyxl` 的只读模式：
```python
from openpyxl import load_workbook

def read_excel_stream(file_obj):
    """流式读取Excel文件"""
    wb = load_workbook(file_obj, read_only=True, data_only=True)
    ws = wb.active
    return ws.iter_rows(min_row=1, values_only=True)
```

对于 CSV 文件，使用 Python 内置 csv 模块：
```python
import csv

def read_csv_stream(file_obj):
    """流式读取CSV文件"""
    reader = csv.reader(file_obj)
    return reader
```

#### 5.2.2 数据验证流程

```
文件上传
    ↓
检查文件格式
    ↓
读取表头
    ↓
验证必填列（配件编号）
    ↓
逐行读取数据
    ↓
    ├─ 验证配件编号非空
    ├─ 验证数据类型（数值字段）
    └─ 检查数据库是否已存在（根据模式）
    ↓
批量保存数据
    ↓
返回导入结果
```

#### 5.2.3 逐行验证规则

| 字段 | 验证规则 |
|------|----------|
| part_number | 必填，去空格，长度 ≤ 510 |
| 数值字段 | 空值转 None，非数值则报错 |
| 字符串字段 | 去空格，超出长度截断或报错 |

### 5.3 DAO 层设计

在 `car_parts_library_benz_dao.py` 中添加批量操作方法：

```python
def bulk_upsert_parts(session, data_list):
    """批量插入或更新配件数据"""
    from sqlalchemy.dialects.mysql import insert
    from app.models.orm_models.car_parts_library_benz import CarPartsLibraryBenz
    
    for data in data_list:
        stmt = insert(CarPartsLibraryBenz).values(**data)
        on_duplicate_key_stmt = stmt.on_duplicate_key_update(
            **{k: v for k, v in data.items() if k != 'part_number'}
        )
        session.execute(on_duplicate_key_stmt)
    session.commit()
```

## 七、内存优化策略

### 7.1 流式读取
- 不使用 `pandas.read_excel()` 读取整个文件
- 使用 `openpyxl` 只读模式逐行迭代
- 使用 `csv.reader` 逐行读取 CSV

### 7.2 批量处理
- 每 100-500 条数据提交一次数据库
- 避免在内存中积累所有数据
- 及时释放已处理行的内存

### 7.3 伪代码示例

```python
def process_file_stream(file_obj, filename, mode='upsert'):
    """流式处理文件"""
    # 1. 读取表头
    header = read_header(file_obj, filename)
    
    # 2. 验证列名
    validate_columns(header)
    
    # 3. 准备列映射
    col_index_map = build_column_index_map(header)
    
    # 4. 初始化统计
    stats = {'total': 0, 'success': 0, 'failed': 0, 'errors': []}
    batch_data = []
    BATCH_SIZE = 100
    
    # 5. 逐行处理
    for row_num, row in enumerate(iter_rows(file_obj, filename), start=2):
        stats['total'] += 1
        
        try:
            # 验证行数据
            validated_data = validate_row(row, col_index_map, row_num)
            
            # 加入批次
            batch_data.append(validated_data)
            
            # 批次满则提交
            if len(batch_data) >= BATCH_SIZE:
                save_batch(batch_data, mode)
                stats['success'] += len(batch_data)
                batch_data = []  # 清空批次，释放内存
                
        except Exception as e:
            stats['failed'] += 1
            stats['errors'].append({
                'row': row_num,
                'part_number': get_part_number_from_row(row, col_index_map),
                'error': str(e)
            })
    
    # 6. 处理剩余数据
    if batch_data:
        save_batch(batch_data, mode)
        stats['success'] += len(batch_data)
    
    return stats
```

## 八、错误处理

### 8.1 错误分类

| 错误类型 | 示例 | 处理方式 |
|----------|------|----------|
| 文件格式错误 | 文件不是 Excel/CSV | 前端拦截，提示用户 |
| 列名错误 | 缺少"配件编号"列 | 后端验证，返回具体错误 |
| 数据验证错误 | 数值列包含非数值 | 记录行号，继续处理其他行 |
| 数据库错误 | 主键冲突 | 根据模式处理（报错或更新） |

### 8.2 错误返回格式

```json
{
    "code": 400,
    "msg": "导入失败，请检查数据",
    "data": {
        "total": 100,
        "success": 50,
        "failed": 50,
        "errors": [
            {
                "row": 2,

            },
            {
                "row": 5,
                "part_number": "ABC123",
                "error": "批发价格格式错误"
            }
        ]
    }
```

## 九、性能优化

1. **批量提交**：每 100-500 条提交一次，减少数据库往返
2. **索引利用**：part_number 已有主键索引，查询效率高
3. **事务管理**：每个批次在独立事务中，失败不影响其他批次
4. **异步处理**：考虑后续扩展为异步任务，避免前端超时

## 十、安全考虑

1. **文件类型验证**：不仅验证扩展名，还要验证文件内容
2. **文件大小限制**：10MB 限制，防止过大文件
3. **SQL 注入防护**：使用 ORM 参数化查询
4. **数据来源标记**：导入数据的 `data_source` 设为 `excel_import`

## 十一、后续扩展

1. **异步任务**：支持大文件异步导入，前端轮询进度
2. **导入预览**：上传后先展示预览，确认后再保存
3. **数据对比**：导入前与现有数据对比，展示变更
4. **导出功能**：支持导出当前查询结果为 Excel
