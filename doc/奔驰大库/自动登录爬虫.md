## 核心类

### 1. MercedesLogin

#### 类概述

负责执行完整的 OAuth2 登录流程，实现从初始页面访问到最终 Cookie 获取的所有步骤。

#### 类属性

| 属性             | 类型  | 说明             |
| -------------- | --- | -------------- |
| `BASE_URL`     | str | 奔驰大库基础 URL     |
| `SSO_URL`      | str | 单点登录 URL       |
| `LOGIN_URL`    | str | 登录页面 URL       |
| `CLIENT_ID`    | str | OAuth2 客户端 ID  |
| `REDIRECT_URI` | str | OAuth2 重定向 URI |
| `SCOPE`        | str | OAuth2 授权范围    |

#### 初始化方法

```python
def __init__(self, username: str, password: str, timeout: int = 30, retry_count: int = 3)
```

**参数说明：**

- `username`: 登录用户名
- `password`: 登录密码
- `timeout`: 请求超时时间（秒），默认 30
- `retry_count`: 重试次数，默认 3

#### 主要方法

##### 1. login()

执行完整的登录流程。

```python
def login(self) -> Tuple[bool, dict]
```

**返回值：**

- 成功: `(True, {"cookie": str})`
- 失败: `(False, {"error": str})`

**登录步骤：**

1. 访问初始页面
2. 访问 OAuth2 授权页面并跟随重定向
3. 从登录页面提取参数（CSRF token、RSA 公钥等）
4. 提交用户名获取 features
5. 获取时间戳
6. 提交登录表单
7. 完成 OAuth2 回调

##### 2. get\_cookie()

获取格式化的 Cookie 字符串。

```python
def get_cookie(self) -> str
```

**返回值：** 格式为 `key1=value1; key2=value2` 的 Cookie 字符串

##### 3. close()

关闭会话连接。

```python
def close()
```

### 2. MercedesLoginService

#### 类概述

提供高级服务功能，封装常用操作，如登录、Cookie 验证、配置管理等。

#### 主要方法

##### 1. login\_and\_get\_cookie()

登录并获取完整登录信息。

```python
@staticmethod
def login_and_get_cookie(username: str, password: str) -> Tuple[bool, dict]
```

**参数说明：**

- `username`: 用户名
- `password`: 密码

**返回值：**

- 成功: `(True, {"cookie": str})`
- 失败: `(False, {"error": str})`

**使用示例：**

```python
from app.scripts.spiders.spider_entities.mercedes_login import MercedesLoginService

success, result = MercedesLoginService.login_and_get_cookie("username", "password")
if success:
    cookie = result["cookie"]
    print("登录成功")
else:
    print(f"登录失败: {result['error']}")
```

##### 2. validate\_cookie()

验证 Cookie 是否有效。

```python
@staticmethod
def validate_cookie(cookie: str, test_part_number: str = "A0002521620", test_customer_id: str = "193211390", test_sales_organization_id: str = "O 50000741") -> Tuple[bool, str]
```

**参数说明：**

- `cookie`: Cookie 字符串
- `test_part_number`: 用于验证的零件编号，默认 "A0002521620"
- `test_customer_id`: 用于验证的客户ID，默认 "193211390"
- `test_sales_organization_id`: 用于验证的销售组织ID，默认 "O 50000741"

**返回值：**

- `(True, "")`: Cookie 有效
- `(False, "错误信息")`: Cookie 无效

**使用示例：**

```python
is_valid, msg = MercedesLoginService.validate_cookie(cookie)
if is_valid:
    print("Cookie 有效")
else:
    print(f"Cookie 无效: {msg}")
```

##### 3. get\_valid\_config()

获取有效的 Cookie，自动处理登录逻辑。

```python
@staticmethod
def get_valid_config() -> str
```

**返回值：** 验证通过的 Cookie 字符串

**执行流程：**

1. 从数据库获取现有配置
2. 验证 Cookie 是否有效
3. 如果验证失败，使用配置中的用户名密码重新登录
4. 保存新配置到数据库
5. 验证新配置
6. 如果验证失败，抛出异常

**使用示例：**

```python
try:
    cookie = MercedesLoginService.get_valid_config()
    print(f"已获取有效的 Cookie: {cookie[:50]}...")
except Exception as e:
    print(f"获取配置失败: {str(e)}")
```

## 登录流程详解

### OAuth2 流程

```
1. 用户访问 /sop-china/
   ↓
2. 重定向到 OAuth2 授权端点 /oauth2/authorization/sop-china
   ↓
3. 重定向到 login.mercedes-benz.com 登录页面
   ↓
4. 用户输入用户名密码（RSA 加密）
   ↓
5. 提交登录表单
   ↓
6. 重定向回 REDIRECT_URI 并携带授权码
   ↓
7. 内部完成 OAuth2 回调
   ↓
8. 获取 Cookie
```

### 核心步骤

#### 步骤 1: 访问初始页面

- URL: `https://dalfsc.aftersales.mercedes-benz.com/sop-china/`
- 目的: 初始化会话，设置基础 Cookie

#### 步骤 2: 访问 OAuth2 授权页面

- URL: `https://dalfsc.aftersales.mercedes-benz.com/oauth2/authorization/sop-china`
- 目的: 开始 OAuth2 流程，获取登录页面的完整 URL（包含参数）

#### 步骤 3: 提取参数

从登录页面和 URL 中提取：

- `_csrf`: CSRF Token
- `data-encryption-key`: RSA 公钥（PEM 格式）
- `resumePath`: 用于登录流程恢复
- `REF`: 引用参数
- `unique_id`: 唯一 ID

#### 步骤 4: 提交用户名

- URL: `https://login.mercedes-benz.com/features`
- 参数: `uid` (用户名，大写)
- 目的: 获取登录特性信息

#### 步骤 5: 获取时间戳

- URL: `https://login.mercedes-benz.com/time`
- 目的: 获取服务器时间，用于密码加密

#### 步骤 6: 提交登录表单

- URL: `https://login.mercedes-benz.com/`
- 表单数据:
  - `username`: 用户名（大写）
  - `password`: 空字符串
  - `password-encrypted`: RSA 加密后的密码
  - `pingResume`: resumePath 参数
  - `instance`: "default"
  - `usedRememberMeSwitchId`: ""
  - `_csrf`: CSRF Token（如果有）

#### 步骤 7: 完成 OAuth2 回调

- URL: `https://dalfsc.aftersales.mercedes-benz.com/sop-china/`
- 目的: 确认 Cookie 设置完成

## 密码加密

### 加密算法

使用 RSA-OAEP SHA-256 加密。

### 加密流程

```python
# 1. 构建数据结构
data = {
    "password": password,
    "timestamp": timestamp
}
data_json = json.dumps(data, separators=(',', ':'))

# 2. 使用 RSA 公钥加密
encrypted = public_key.encrypt(
    data_json.encode('utf-8'),
    padding.OAEP(
        mgf=padding.MGF1(algorithm=hashes.SHA256()),
        algorithm=hashes.SHA256(),
        label=None
    )
)

# 3. Base64 编码
encrypted_password = base64.b64encode(encrypted).decode('utf-8')
```

## 注意事项

### 1. Cookie 有效期

- Cookie 可能会过期
- `MercedesDalfscSpider` 初始化时会自动验证和处理 Cookie
- 使用 `get_valid_config()` 自动处理刷新

### 2. 安全

- 密码需要加密后传输
- 不要在代码中硬编码用户名密码
- 使用配置存储登录凭据

### 3. 错误处理

- 所有网络请求都可能失败，需要适当处理异常
- 登录过程中任何步骤失败都会返回清晰的错误信息

### 4. 性能

- Cookie 验证需要网络请求，不要频繁调用
- 使用配置缓存减少数据库查询
- 推荐使用 `get_valid_config()` 自动管理登录状态

## 常见问题

### Q: 为什么不使用 Playwright 等浏览器自动化工具？

A: 纯 API 实现性能更好，不需要启动浏览器，资源消耗更少。

### Q: Cookie 过期了怎么办？

A: 使用 `MercedesLoginService.get_valid_config()` 或直接初始化 `MercedesDalfscSpider()` 会自动检测 Cookie 有效性，并在失效时重新登录。

### Q: 如何设置初始配置？

A: 可以使用 `update_json_config()` 或通过系统配置界面设置。

### Q: 登录失败怎么办？

A: 检查以下内容：

1. 用户名密码是否正确
2. 网络连接是否正常
3. 网站是否有更新（可能需要重新分析登录流程）
