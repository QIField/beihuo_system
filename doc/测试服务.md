## 🎯 核心设计理念

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                   │
│  业务代码 (app/api/..., app/routes/...)                            │
│      ↓ 无需修改                                                    │
│  测试文件中使用 register_testable() 注册                            │
│      ↓ （等效于"加装饰器"，但不影响原代码）                         │
│  框架自动收集所有被标记的内容                                        │
│      ↓                                                             │
│  调用 start_test_server() 或 create_test_client()                   │
│      ↓                                                             │
│  🎉 服务自动启动，所有端点就绪                                        │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

**关键优势：解耦！**

- ✅ 不修改业务代码
- ✅ 不需要写 Flask 应用创建代码
- ✅ 不需要手动注册路由
- ✅ 自动生成控制台页面 `http://localhost:5001/testable/`

## 💡 四种核心使用模式

### 📌 模式 1：注册项目的 Blueprint（最常用）

```python
# tests/my_test.py
from tests.testable_framework import register_testable, start_test_server

# 1. 导入项目中的 Blueprint
from app.api.system_management_api.permission_api import permission_bp
from app.routes.permission_manager_web import permission_manager_web_bp

# 2. 注册（这就是"加装饰器"的等效操作）
register_testable(permission_bp, url_prefix='/api')
register_testable(permission_manager_web_bp)

# 3. 启动服务
start_test_server(port=5001)
```

运行：`python -m tests.my_test`

***

### 📌 模式 2：装饰独立函数创建测试端点

```python
from tests.testable_framework import testable_route, start_test_server
from flask import jsonify, request

# 用装饰器把普通函数变成路由
@testable_route('/api/test/hello', methods=['GET'])
def hello():
    return jsonify({'message': 'Hello!'})

@testable_route('/api/test/calc', methods=['POST'])
def calc():
    data = request.get_json()
    return jsonify({'result': data['a'] + data['b']})

# 启动服务
start_test_server(port=5001)
```

***

### 📌 模式 3：单元测试（使用 test\_client，不需要真实服务器）

```python
from tests.testable_framework import register_testable, create_test_client
import json

# 1. 注册要测试的内容
from app.api.system_management_api.permission_api import permission_bp
register_testable(permission_bp, url_prefix='/api')

# 2. 创建测试客户端（内存中执行，没有网络开销）
client = create_test_client()

# 3. 测试 GET
resp = client.get('/api/permissions')
print('状态码:', resp.status_code)
print('响应:', resp.get_json())

# 4. 测试 POST
resp = client.post('/api/permissions',
                   data=json.dumps({'permission_name': '测试'}),
                   content_type='application/json')
print('状态码:', resp.status_code)
```

***

### 📌 模式 4：结合 unittest 编写正式测试

```python
import unittest
from tests.testable_framework import register_testable, create_test_client

class PermissionAPITest(unittest.TestCase):
    
    @classmethod
    def setUpClass(cls):
        # 注册一次，供所有测试用例使用
        from app.api.system_management_api.permission_api import permission_bp
        register_testable(permission_bp, url_prefix='/api')
    
    def setUp(self):
        # 每个测试用例都获得一个新的测试客户端
        self.client = create_test_client()
    
    def test_get_permissions(self):
        resp = self.client.get('/api/permissions')
        self.assertEqual(resp.status_code, 200)
        data = resp.get_json()
        self.assertEqual(data['code'], 200)
    
    def test_create_permission(self):
        import json
        resp = self.client.post('/api/permissions',
                               data=json.dumps({'permission_name': '测试'}),
                               content_type='application/json')
        self.assertEqual(resp.status_code, 200)

if __name__ == '__main__':
    unittest.main()
```

## 📝 常用 API 速查表

### 注册内容

```python
from tests.testable_framework import register_testable, testable_route, testable_func

# 注册 Flask Blueprint
register_testable(my_bp, url_prefix='/api')

# 装饰普通函数变成路由
@testable_route('/my/endpoint', methods=['GET'])
def my_func():
    from flask import jsonify
    return jsonify({'ok': True})

# 装饰函数（用于直接调用测试，不注册到路由）
@testable_func(name='我的函数')
def my_calc(a, b):
    return a + b
```

### 启动服务 / 创建客户端

```python
from tests.testable_framework import start_test_server, create_test_client, TestServer

# 方式 A：启动阻塞式服务（浏览器测试用）
start_test_server(port=5001)

# 方式 B：创建单元测试客户端（自动化测试用）
client = create_test_client()
resp = client.get('/api/something')

# 方式 C：with 语句中使用（集成测试用）
with TestServer(port=5002) as server:
    url = server.url('/api/test')
    # 在此范围内发送 HTTP 请求
```

## 💡 最佳实践建议

1. **优先使用** **`register_testable()`**（不修改原代码，最灵活）
2. **单元测试用** **`create_test_client()`**（速度快，适合 CI/CD）
3. **手动调试用** **`start_test_server()`**（启动服务后用浏览器/Postman 测试）
4. **每个测试文件独立注册**（避免全局状态互相干扰，需要时调用 `reset_registry()`）

现在你可以运行 `python -m tests.testable_quick_start` 来启动测试服务，然后在浏览器中测试权限 API！
