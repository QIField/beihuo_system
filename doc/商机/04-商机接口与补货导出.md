# 商机接口

## 一、接口列表

所有接口注册在 `/new/api/niche` 下：

| 接口 | 方法 | 服务 | 说明 |
|------|------|------|------|
| `/list` | GET | `opportunity_query_service` | 商机列表分页查询 |
| `/summary` | GET | `opportunity_query_service` | 商机统计摘要 |
| `/top` | GET | `opportunity_query_service` | Top N 商机 |

> **注**：`/export_replenish`（导出补货清单）和 `/trigger_compute`（手动触发计算）已下线。商机数据由每日凌晨 2:00 定时任务自动刷新，不再提供前端手动刷新和导出入口。

## 二、接口详情

### 2.1 `/list` — 商机列表

**请求参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `keyword` | string | 否 | '' | 关键词，匹配 OE 码 / 品牌 / 配件名称 |
| `opportunity_level` | string | 否 | '' | 商机等级 S/A/B/C/D |
| `min_score` | float | 否 | 0 | 最低商机评分 |
| `min_oos_rate` | float | 否 | 0 | 最低缺货率 |
| `has_replenish` | int | 否 | 0 | 是否有补货建议，1=是 |
| `page` | int | 否 | 1 | 页码 |
| `limit` | int | 否 | 50 | 每页条数，最大 500 |
| `sort_field` | string | 否 | '' | 排序字段名 |
| `sort_order` | string | 否 | 'desc' | asc / desc |

**默认排序**：商机等级（S→A→B→C→D）+ 商机评分降序。

### 2.2 `/summary` — 统计摘要

返回各等级商机数量及有补货建议的记录数：

```json
{
  "code": 200,
  "data": {
    "S": 10,
    "A": 20,
    "B": 30,
    "C": 40,
    "D": 50,
    "replenish": 25
  }
}
```

### 2.3 `/top` — Top N 商机

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `top_n` | int | 否 | 10 | 返回数量 |

## 三、查询服务逻辑

`opportunity_query_service` 仅负责读取 `niche_opportunity` 表：

- 关键词搜索：`oe_code`、`brand_name`、`part_name` 模糊匹配
- 等级筛选：`opportunity_level` 精确匹配
- 最低评分：`opportunity_score >= min_score`
- 最低缺货率：`out_of_stock_rate_30d >= min_oos_rate`
- 补货建议：`replenish_suggestion > 0`
- 排序：支持任意模型字段升降序，默认按等级 + 评分
