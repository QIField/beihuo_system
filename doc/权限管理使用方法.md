# 权限管理使用文档

## 快速开始

### 三步使用装饰器

**1. 登记权限码**（后台权限管理页面）

在 `crmapp_permissions` 表或后台页面登记权限码，格式为 `模块:操作`，例如 `cart:delete`、`user:view`、`report:export`。

**2. 分配权限给角色**（后台角色管理页面）

将权限码分配给对应的角色（如 `business_manager`），再将角色分配给用户。

**3. 在接口上添加装饰器**

```python
from flask import Blueprint, jsonify
from app.core.permission import require_permission

bp = Blueprint('cart', __name__, url_prefix='/api/cart')

@bp.route('/delete', methods=['POST'])
@require_permission('cart:delete')   # ← 加这一行即可
def delete_cart():
    return jsonify({'code': 0, 'msg': '删除成功'})
```

无权限时返回：
```json
{ "code": 403, "msg": "权限不足，需要权限: cart:delete", "data": null }
```

未登录时返回：
```json
{ "code": 401, "msg": "未登录，请先登录", "data": null }
```

## 装饰器一览

| 装饰器 | 作用 | 示例 |
|--------|------|------|
| `@require_authentication()` | 仅检查是否登录（API 版，返回 JSON 错误） | 登录后可访问的通用接口 |
| `@require_page_login()` | 仅检查是否登录（页面版，未登录渲染登录页） | 登录后可访问的页面路由 |
| `@require_permission('code')` | 检查是否拥有指定权限码（API 版，最常用） | `@require_permission('cart:delete')` |
| `@require_page_permission('code')` | 检查是否拥有指定权限码（页面版） | `@require_page_permission('cart:view')` |
| `@require_any_permission(['a','b'])` | 拥有任一权限码即可 | 仪表盘、统计报表 |
| `@require_all_permissions(['a','b'])` | 必须同时拥有所有权限码 | 敏感操作如删除用户 |
| `@require_role('code')` | 检查是否拥有指定角色 | `@require_role('super_admin')` |
| `@require_any_role(['a','b'])` | 拥有任一角色即可 | `@require_any_role(['super_admin','store_admin'])` |
| `@require_admin()` | 等价于 `@require_role('super_admin')` | 超管专属接口 |
| `@require_any_admin()` | 等价于 `@require_any_role(['super_admin','store_admin'])` | 管理员入口 |
| `@require_custom_check(func, msg)` | 自定义业务检查 | 基于门店、时间等复杂逻辑 |

## 各装饰器详细用法

### 1. `@require_authentication()` — 登录验证（API 版）

```python
from app.core.permission import require_authentication

@bp.route('/profile', methods=['GET'])
@require_authentication()
def profile():
    return jsonify({'code': 0, 'msg': 'success'})
```

未登录时返回 JSON 错误：
```json
{ "code": 401, "msg": "未登录，请先登录", "data": null }
```

### 2. `@require_page_login()` — 登录验证（页面版）

适用于页面路由，未登录时渲染登录页面而不是返回 JSON 错误。

```python
from app.core.permission import require_page_login

@bp.route('/dashboard')
@require_page_login()
def dashboard():
    return render_template('dashboard.html')
```

自定义登录页面模板：

```python
@bp.route('/admin/settings')
@require_page_login(login_template='admin/login.html')
def admin_settings():
    return render_template('admin/settings.html')
```

### 3. `@require_page_permission('permission_code')` — 页面单权限检查

适用于页面路由，检查用户是否登录并拥有指定权限。
- 未登录 → 渲染登录页面
- 权限不足 → 渲染权限不足页面

```python
from app.core.permission import require_page_permission

@bp.route('/inventory/manage')
@require_page_permission('inventory:manage')
def inventory_manage():
    return render_template('inventory/manage.html')
```

自定义模板：

```python
@bp.route('/admin/settings')
@require_page_permission(
    'admin:settings',
    login_template='admin/login.html',
    forbidden_template='admin/forbidden.html'
)
def admin_settings():
    return render_template('admin/settings.html')
```

### 4. `@require_permission('permission_code')` — 单权限检查（最常用）

```python
from app.core.permission import require_permission

@bp.route('/items', methods=['GET'])
@require_permission('inventory:view')
def get_items():
    return jsonify({'code': 0, 'msg': 'success'})

@bp.route('/delete', methods=['POST'])
@require_permission('inventory:delete')
def delete_item():
    return jsonify({'code': 0, 'msg': 'success'})
```

权限码命名规则：**`模块名:操作名`**，例如 `daily_inventory:update`、`user:view`。

### 5. `@require_any_permission(['code1','code2'])` — 多权限 OR 检查

```python
from app.core.permission import require_any_permission

@bp.route('/dashboard', methods=['GET'])
@require_any_permission(['dashboard:view', 'report:view', 'admin:view'])
def dashboard():
    """拥有以上任一权限即可访问"""
    return jsonify({'code': 0, 'msg': 'success'})
```

### 6. `@require_all_permissions(['code1','code2'])` — 多权限 AND 检查

```python
from app.core.permission import require_all_permissions

@bp.route('/admin/delete-user', methods=['POST'])
@require_all_permissions(['user:view', 'user:delete', 'audit:log'])
def delete_user():
    """必须同时拥有以上所有权限"""
    return jsonify({'code': 0, 'msg': '删除成功'})
```

### 7. `@require_role('role_code')` — 单角色检查

```python
from app.core.permission import require_role

@bp.route('/admin/settings', methods=['GET'])
@require_role('super_admin')
def admin_settings():
    return jsonify({'code': 0, 'msg': 'success'})
```

### 8. `@require_any_role(['role1','role2'])` — 多角色 OR 检查

```python
from app.core.permission import require_any_role

@bp.route('/management', methods=['GET'])
@require_any_role(['super_admin', 'store_admin', 'business_manager'])
def management_page():
    """拥有以上任一角色即可访问"""
    return jsonify({'code': 0, 'msg': 'success'})
```

### 9. `@require_admin()` / `@require_any_admin()` — 便捷装饰器

```python
from app.core.permission import require_admin, require_any_admin

# 等价于 @require_role('super_admin')
@bp.route('/admin/system-config', methods=['POST'])
@require_admin()
def system_config():
    return jsonify({'code': 0, 'msg': 'success'})

# 等价于 @require_any_role(['super_admin', 'store_admin'])
@bp.route('/admin/store-config', methods=['POST'])
@require_any_admin()
def store_config():
    return jsonify({'code': 0, 'msg': 'success'})
```

### 10. `@require_custom_check(func, msg)` — 自定义检查

适用于权限码、角色无法表达的复杂业务逻辑。

自定义函数签名：`func(user_id) -> bool`

```python
from app.core.permission import require_custom_check
from flask import request

def check_store_access(user_id: int) -> bool:
    """检查用户是否有权访问当前门店"""
    store_id = request.args.get('store_id')
    return verify_user_store_permission(user_id, store_id)

@bp.route('/store/special-data', methods=['GET'])
@require_custom_check(check_store_access, "无权访问当前门店数据")
def special_data():
    return jsonify({'code': 0, 'msg': 'success'})
```

## 完整开发示例

**需求**：新增「客户额度审核」接口，仅拥有 `customer_quota:audit` 权限的用户可访问。

### 步骤 1：登记权限码

在后台权限管理页面添加：
- 权限名称：`客户额度审核`
- 权限编码：`customer_quota:audit`
- 类型：`操作权限`

### 步骤 2：分配权限给角色

在角色权限分配页面，将 `customer_quota:audit` 权限勾选到 `business_manager` 角色。

### 步骤 3：将角色分配给用户

在用户角色分配页面，给用户分配 `business_manager` 角色。

### 步骤 4：写接口代码

```python
from flask import Blueprint, request, jsonify
from app.core.permission import require_permission
from app.services.customer_quota_service import audit_quota

customer_quota_bp = Blueprint('customer_quota', __name__, url_prefix='/api/customer-quota')

@customer_quota_bp.route('/audit', methods=['POST'])
@require_permission('customer_quota:audit')
def api_audit_quota():
    data = request.get_json(force=True)
    result = audit_quota(data)
    return jsonify({'code': 0, 'msg': 'success', 'data': result})
```

### 步骤 5：注册 Blueprint 并测试

1. 在 `app/__init__.py` 中注册 `customer_quota_bp`
2. 有权限账号调用 → 正常返回
3. 无权限账号调用 → 返回 403 错误

## 常见问题

### Q1：接口报错「权限检查器未初始化」？

在 Flask app 启动函数中添加：
```python
from app.services.permission_service import init_permission_checkers
init_permission_checkers()
```

项目中 `app/__init__.py` 已自动完成此初始化。

### Q2：权限改了，但用户权限没更新？

权限检查有 30 分钟缓存。权限变更后调用：
```python
from app.services.permission_service import PermissionService
PermissionService.clear_cache(user_id=123)   # 清理指定用户缓存
PermissionService.clear_cache()              # 清理所有权限缓存
```

### Q3：权限码正确，还是返回 403？

依次检查：
1. 用户是否已登录
2. 用户是否分配了角色
3. 角色是否勾选了对应权限码
4. 角色的有效期 `start_time` / `end_time` 是否包含当前时间

### Q4：如何在前端根据权限控制按钮显隐？

提供一个查询当前用户权限列表的接口：

```python
@bp.route('/my-permissions', methods=['GET'])
@require_authentication()
def my_permissions():
    from flask import session
    from app.services.permission_service import PermissionService
    perms = PermissionService.get_user_permissions(session['user_id'])
    return jsonify({'code': 0, 'data': sorted(perms)})
```

前端拿到权限码列表后，根据需要控制 UI 显隐。
