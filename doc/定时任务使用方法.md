# task_manager 全局单例使用方法

## 全局单例

`task_manager` 是系统唯一的任务管理器实例，已在模块加载时自动创建：

```python
from app.core.task_manager import task_manager
```

## 核心方法

### 1. initialize()

初始化线程池和调度器，**必须在使用前调用**。

```python
task_manager.initialize()
```

### 2. submit(func, *args, **kwargs)

提交即时异步任务。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `func` | Callable | 是 | 要执行的函数 |
| `*args` | Any | 否 | 函数的位置参数 |
| `**kwargs` | Any | 否 | 函数的关键字参数 |

返回值：`concurrent.futures.Future` 对象，可通过 `future.result()` 获取结果。

示例：

```python
future = task_manager.submit(my_func, arg1, arg2=value)
result = future.result()
```

### 3. schedule(func, trigger, job_id, replace_existing=True, next_run_time=None, **trigger_args)

**添加定时任务（核心方法）**

#### 参数详解

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `func` | Callable | 是 | 定时执行的函数，无参数 |
| `trigger` | str | 是 | 触发器类型：`'interval'`（间隔）或 `'cron'`（定时） |
| `job_id` | str | 是 | 任务唯一标识，用于区分不同任务 |
| `replace_existing` | bool | 否 | 是否替换已存在的同名任务，默认 `True` |
| `next_run_time` | datetime | 否 | 首次执行时间，默认自动计算，设置为 `datetime.now()` 可立即执行 |
| `**trigger_args` | dict | 是 | 触发器的时间参数，根据 trigger 类型不同 |

#### trigger='interval'（间隔触发器）

按固定间隔执行，`trigger_args` 支持以下参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `seconds` | int/float | 间隔秒数 |
| `minutes` | int/float | 间隔分钟数 |
| `hours` | int/float | 间隔小时数 |
| `days` | int/float | 间隔天数 |
| `weeks` | int/float | 间隔周数 |

示例：

```python
# 每5分钟执行一次
task_manager.schedule(
    func=my_task,
    trigger='interval',
    job_id='my_interval_job',
    minutes=5,
    replace_existing=True
)

# 每30秒执行一次
task_manager.schedule(
    func=heartbeat,
    trigger='interval',
    job_id='heartbeat',
    seconds=30
)

# 每2小时执行一次，首次立即执行
from datetime import datetime
task_manager.schedule(
    func=sync_data,
    trigger='interval',
    job_id='sync_data',
    hours=2,
    next_run_time=datetime.now()
)
```

#### trigger='cron'（Cron 触发器）

按指定时间点执行，`trigger_args` 支持以下参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `year` | int/str | 年份（如 2024） |
| `month` | int/str | 月份（1-12） |
| `day` | int/str | 日期（1-31） |
| `week` | int/str | 周数（1-53） |
| `day_of_week` | int/str | 星期几（0-6 或 mon-sun） |
| `hour` | int/str | 小时（0-23） |
| `minute` | int/str | 分钟（0-59） |
| `second` | int/str | 秒（0-59） |

支持表达式，如 `hour='9-18'`（9点到18点）、`minute='*/15'`（每15分钟）。

示例：

```python
# 每天9:15执行
task_manager.schedule(
    func=daily_report,
    trigger='cron',
    job_id='daily_report',
    hour=9,
    minute=15
)

# 每周一、三、五 10:00 执行
task_manager.schedule(
    func=weekly_sync,
    trigger='cron',
    job_id='weekly_sync',
    day_of_week='mon,wed,fri',
    hour=10
)

# 每月1号凌晨3点执行
task_manager.schedule(
    func=monthly_stat,
    trigger='cron',
    job_id='monthly_stat',
    day=1,
    hour=3
)

# 工作日（周一至周五）8:30-18:00 每小时执行一次
task_manager.schedule(
    func=business_hour_task,
    trigger='cron',
    job_id='business_hour',
    day_of_week='mon-fri',
    hour='8-18',
    minute=30
)
```

### 4. get_jobs()

获取当前所有定时任务列表。

返回格式：

```python
[
    {'id': 'job_id', 'name': 'func_name', 'next_run_time': '2024-01-01 09:00:00'},
    ...
]
```

### 5. shutdown(wait=True)

关闭任务管理器，释放资源。

| 参数 | 类型 | 说明 |
|------|------|------|
| `wait` | bool | 是否等待正在执行的任务完成，默认 `True` |

## 使用流程

```python
from app.core.task_manager import task_manager
from datetime import datetime

# 1. 初始化（全局只需调用一次）
task_manager.initialize()

# 2. 添加定时任务
def my_task():
    print("任务执行中")

task_manager.schedule(
    func=my_task,
    trigger='interval',
    job_id='my_task',
    minutes=5,
    replace_existing=True
)

# 3. 提交即时任务
future = task_manager.submit(lambda: "即时任务结果")
result = future.result()

# 4. 查看任务列表
print(task_manager.get_jobs())

# 5. 关闭（程序退出时调用）
task_manager.shutdown()
```

## 注意事项

1. `func` 参数必须是无参数函数，如果需要传递参数，请使用闭包或 `functools.partial`
2. `job_id` 必须唯一，重复的 `job_id` 会被替换（当 `replace_existing=True` 时）
3. 定时任务执行时会自动捕获并记录异常，不会影响调度器运行
4. 时区默认为 `Asia/Shanghai`（东八区）
