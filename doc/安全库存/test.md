安全库存算法公式汇总

配置参数速查

参数          A类      B类      C类
Z系数         1.5      1.2      0.8
覆盖天数      10       20       30
产品占比      20%      60%      20%

其他参数：
补货周期 = 1天
季节系数范围 = 0.7 ~ 1.3
积压阈值 = 1.3倍
预警天数 = 3天


1. 基础安全库存公式
基础安全库存 = Z系数 × 销量标准差 × 补货周期
注释：应对销量波动所需的基础缓冲库存
Z系数：A类=1.5(高保护), B类=1.2(中保护), C类=0.8(低保护)
标准差越大、补货周期越长，安全库存越高

2. 季节系数计算
季节系数 = 当月销量 / 全年平均月销量
注释：判断当前是旺季还是淡季，范围限制0.7~1.3
>1: 旺季多备货, <1: 淡季少备货

3. 调整后安全库存
调整后安全库存 = 基础安全库存 × 季节系数
注释：根据季节因素调整后的最终安全库存

4. 库存下限（再订货点）
库存下限 = 平均日销量 × 补货周期 + 安全库存
注释：库存降至此值时应立即补货
包含补货期间的销售量 + 安全缓冲

5. 库存上限（目标库存）
库存上限 = 平均日销量 × (补货周期 + 覆盖天数) + 安全库存
注释：库存不应超过此值
覆盖天数：A=10天, B=20天, C=30天

6. 可卖天数
可卖天数 = 可用库存 / 平均日销量
注释：按当前销售速度，库存还能卖几天

7. 库存状态判定
if 可卖天数 <= 补货周期(1天):
状态 = "需补货"      立即补货，防止断货

elif 可卖天数 <= 预警天数(3天):
状态 = "库存偏低"    关注并准备补货

elif 可用库存 > 库存上限 × 1.3:
状态 = "库存积压"    库存过多，考虑促销

else:
状态 = "正常"        库存健康
