# 01 设计概述与销量计算

## 1.1 拆分动机

原 `oe_parts_sales` 单表混合了两类职责：
- **销量数据采集**：日/月/年销量、销量标准差、月度销量 JSON 等，由数据采集任务维护；
- **安全库存计算与展示**：ABC 分类、安全库存阈值、库存状态等，由库存计算任务维护并供前端展示。

两类数据的更新频率、数据来源、消费方均不同，混表会导致采集任务与计算任务耦合、字段语义不清。拆分后职责单一，便于独立维护与扩展。

## 1.2 两表定位

| 表名 | 定位 | 数据来源 | 主要消费方 |
|------|------|---------|-----------|
| `oe_parts_sales`（销量表） | 安全库存计算的数据来源，存储按 (OE号, 品牌) 汇总的净销量统计 | `sales_order_history`（无退货常规订单）+ `stock_safe_refund_ref`（type=21/22 部分退货净额） | 安全库存计算任务 |
| `stock_safe`（安全库存表） | 前端展示用，存储安全库存计算结果与库存状态 | 销量表同步 + 外部可用库存 + 计算逻辑 | 前端页面、库存预警 |

## 1.3 移除 `stat_date` 字段说明

- **销量表**：数据时效由 `updated_at` 体现（每次采集刷新即更新），无需单独的统计日期字段；
- **安全库存表**：为计算快照，通过定时任务整体刷新，逐条统计日期无业务意义。

故两表均不保留 `stat_date` 字段。

## 1.4 销量数据来源与计算逻辑

> 销量表 `oe_parts_sales` 的销量数据来源于 `sales_order_history` 与 `stock_safe_refund_ref` 两表，按 (oe, brand_name) 聚合计算**净销量**。

### 1.4.1 净销量计算公式

```
某(oe, brand_name)的净销量 = 
    Σ quantity                  -- 第一部分：sales_order_history 中 order_type_id=1 且 orders_items_id 不在
                                   stock_safe_refund_ref.normal_order_items_id 的常规订单
  + Σ processed_quantity        -- 第二部分：stock_safe_refund_ref 中 type IN(21,22) 且为该
                                   normal_order_items_id 最新(match_count最大)记录的 processed_quantity
```

### 1.4.2 第一部分 — 来自 sales_order_history（无退货的常规订单）

- 取 `order_type_id=1`（常规订单）
- **排除** `orders_items_id` 已存在于 `stock_safe_refund_ref.normal_order_items_id` 的订单（这些订单有退货记录，不从销量表取原始数量，改由第二部分按净额计入）
- 剩余订单按 `quantity` 字段计入销量
- 时间维度：按 `create_date`（秒级时间戳）划分日/月/年

### 1.4.3 第二部分 — 来自 stock_safe_refund_ref（有部分退货的常规订单）

- 取 `type IN (21, 22)`（部分退货，常规订单有剩余，processed_quantity > 0）
- 对同一 `normal_order_items_id`，取 `match_count = MAX(match_count)` 的最新记录（与现有 DAO `get_type21_22_records` 逻辑一致，`stock_safe_refund_ref_dao.py:563-594`）
- `processed_quantity` 字段即为该常规订单的净销量（扣除退货后的剩余数量）

### 1.4.4 销量计算 type 处理矩阵

| stock_safe_refund_ref type | 含义 | 是否从 sales_order_history 取原始 quantity | 是否从 stock_safe_refund_ref 取 processed_quantity | 净销量 |
|---|---|---|---|---|
| 11/12/13 | 完全退货（processed_quantity=0） | 否（已排除） | 否 | 0 |
| 21/22 | 部分退货（有剩余） | 否（已排除） | 是（取最新 match_count 的 processed_quantity） | processed_quantity |
| 23/31/32/33 | 退货视角/退货超出 | 否（已排除） | 否（忽略） | 0 |
| 不在 stock_safe_refund_ref | 无退货 | 是（取 quantity） | — | quantity |

### 1.4.5 字段映射（source → oe_parts_sales）

| oe_parts_sales 字段 | sales_order_history 来源 | stock_safe_refund_ref 来源 |
|---------------------|------------------------|---------------------------|
| oe | `number` | `oe` |
| brand_name | `brand_name` | `brand_name` |
| product_name | `pdname` | `product_name` |
| barcode | `frey_no` | `barcode` |
| 销量数值 | `quantity`（无退货订单） | `processed_quantity`（type=21/22 最新） |
| create_date（用于按日/月/年聚合） | `create_date`（秒级时间戳） | — |
