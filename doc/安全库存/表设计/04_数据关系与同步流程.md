# 04 数据关系与同步流程

## 4.1 整体数据流向

```
┌──────────────────────────┐         ┌──────────────────────────────┐
│   sales_order_history    │         │    stock_safe_refund_ref     │
│   (CRM订单明细，爬虫入库)  │         │   (退货关联匹配表)            │
├──────────────────────────┤         ├──────────────────────────────┤
│ orders_items_id (PK)     │         │ normal_order_items_id ───────┼─┐
│ orders_id                │         │ refund_order_items_id        │ │

│ create_date (时间戳)     │         │ match_count                  │ │
└───────────┬──────────────┘         └──────────────┬───────────────┘ │
            │                                       │                 │

            │                                       │                 │
            └───────────────┬───────────────────────┘                 │

                ┌─────────────────────────┐                          │
```

## 4.2 关联关系说明

- **销量表数据来源**：`sales_order_history`（无退货常规订单的 `quantity`）+ `stock_safe_refund_ref`（type=21/22 最新记录的 `processed_quantity`），按 (oe, brand_name) 聚合。`stock_safe_refund_ref.normal_order_items_id` 关联 `sales_order_history.orders_items_id`，用于排除有退货记录的常规订单。
- **销量表 ↔ 安全库存表**：通过 (oe, brand_name) 建立 **1:1** 关联，两表均为 `uk_oe_brand` 唯一键。安全库存表从销量表同步 `avg_daily_sales` 并读取 `sales_std_dev_1y`、`monthly_sales_json`、`avg_monthly_sales_1y` 计算库存阈值。
- **无物理外键**：各表通过应用层维护关联，不建立物理外键，避免采集与计算任务相互阻塞。

## 4.3 数据同步流程

```
[CRM系统] ──爬虫──► sales_order_history（订单明细）
                          │
[退货匹配任务] ──► stock_safe_refund_ref（退货关联，type=11~33）
                          │
                  销量计算任务（按 oe+brand 聚合净销量）
                    ├─ 读取 sales_order_history：order_type_id=1 且未在 refund_ref 的订单 quantity
                    └─ 读取 stock_safe_refund_ref：type=21/22 最新 processed_quantity
                          │
                          ▼
                   oe_parts_sales（销量表，净销量统计）
                          │
                    安全库存计算任务
                    ├─ 同步 avg_daily_sales
                    ├─ 读取 sales_std_dev_1y / monthly_sales_json / avg_monthly_sales_1y
                    ├─ 读取 abc_classification（决定Z系数/覆盖天数）
                    └─ 计算 base/adjusted safety_stock、上下限
                          │
[外部库存系统] ──同步──► available_stock
                          │
                          ▼
                   计算 sellable_days / stock_status
                          │
                          ▼
                   stock_safe（安全库存表）──► 前端展示 / 预警
```

> 销量计算任务与安全库存计算任务的详细流程见 [oe_parts_sales生成流程](../oe_parts_sales生成流程.md)。
