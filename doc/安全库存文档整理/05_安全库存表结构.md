# 安全库存表结构（stock_safe）

> 字段以程序 DAO 为准（`app/dao/stock_safe_dao/stock_safe_dao.py`）。

## 一、字段说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT UNSIGNED, PK | - | 主键ID |
| number | VARCHAR(255), NOT NULL | - | OE号，关联销量表 |
| brand_name | VARCHAR(255), NOT NULL | - | 品牌名，与number共同唯一 |
| pdname | VARCHAR(255) | NULL | 产品名称（冗余） |
| frey_no | VARCHAR(255) | NULL | 条码（冗余） |
| abc_classification | CHAR(1) | NULL | ABC分类（A/B/C），决定Z系数与覆盖天数 |
| avg_daily_sales | DECIMAL(12,2) | 0.00 | 平均日销量（从销量表同步） |
| base_safety_stock | DECIMAL(12,2) | 0.00 | 基础安全库存 = Z × σ_w × √(L/7) |
| season_coefficient | DECIMAL(4,2) | 1.00 | 季节系数，范围 0.7~1.3 |
| safety_stock | DECIMAL(12,2) | 0.00 | 调整后安全库存 = 基础 × 季节系数 |
| stock_lower_limit | DECIMAL(12,2) | 0.00 | 库存下限 = D_avg × L + safety_stock |
| stock_upper_limit | DECIMAL(12,2) | 0.00 | 库存上限 = D_avg × (L + R) + safety_stock |
| available_stock | INT | 0 | 可用库存（来自 crmapp_beihuo） |
| sellable_days | DECIMAL(12,2) | 0.00 | 可卖天数 = avail / avg_daily_sales |
| stock_status | VARCHAR(20) | '正常' | 库存状态 |
| created_at | DATETIME | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

## 二、字段与公式对应关系

| 公式 | 字段 | 输入来源 |
|------|------|---------|
| SS = Z × σ_w × √(L/7) | base_safety_stock | Z(ABC配置)、σ_w(销量表)、L=1 |
| SF = S_m / S_avg | season_coefficient | monthly_sales_json、avg_monthly_sales_1y |
| SS_adj = SS × SF | safety_stock | base_safety_stock × season_coefficient |
| ROP = D_avg × L + SS_adj | stock_lower_limit | avg_daily_sales、safety_stock |
| Max = D_avg × (L+R) + SS_adj | stock_upper_limit | avg_daily_sales、safety_stock、cover(ABC) |
| DOS = avail / D_avg | sellable_days | available_stock / avg_daily_sales |

## 三、可用的库存状态值

| stock_status 值 | 说明 |
|----------------|------|
| 呆滞清库 | annual_sales_1y == 0 |
| 慢动销去库 | annual_sales_1y <= 12 |
| 紧急补货 | avail == 0 或 avail <= safety_stock |
| 需补货 | avail <= lower |
| 库存积压 | avail >= upper × 1.3 |
| 正常 | 以上均不满足 |
