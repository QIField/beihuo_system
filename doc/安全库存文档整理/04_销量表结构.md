# 销量表结构（oe_parts_sales）

> 字段以程序 DAO 为准（`app/dao/stock_safe_dao/build_oe_parts_sales.py`），与 `sales_order_history` 同名同义。

## 一、字段说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT UNSIGNED, PK | - | 主键ID |
| number | VARCHAR(255), NOT NULL | - | OE号 |
| brand_name | VARCHAR(255) | NULL | 品牌名，与number共同唯一 |
| pdname | VARCHAR(255) | NULL | 产品名称 |
| frey_no | VARCHAR(255) | NULL | 条码 |
| avg_daily_sales_1y | DECIMAL(12,2) | 0.00 | 近12月平均日净销量 = 总净销量/实际天数 |
| avg_monthly_sales_1y | DECIMAL(12,2) | 0.00 | 近12月平均月净销量 = 总净销量/12 |
| annual_sales_1y | INT | 0 | 近12个月总净销量 |
| sales_this_year | INT | 0 | 当前自然年总净销量 |
| sales_last_year | INT | 0 | 上一完整自然年总净销量 |
| sales_std_dev_1y | DECIMAL(12,2) | 0.00 | 近52周各周净销量总体标准差（ddof=0） |
| monthly_sales_json | JSON | NULL | 近12个月各月净销量 `{"YYYY-MM": 数量}` |
| weekly_sales_json | JSON | NULL | 近52周各周净销量 `{"YYYY-MM-DD": 数量}` |
| stat_date | DATE | NULL | 统计日期（上月最后一天） |
| created_at | DATETIME | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

> **注意**：`sales_std_dev_1y` 基于 **52 周**净销量计算，而非月度数据。见 [02_管控原则与统计](02_安全库存管控原则与统计.md) 第三节。

## 二、索引设计

| 索引名 | 类型 | 字段 | 用途 |
|--------|------|------|------|
| PRIMARY | 主键 | id | 主键 |
| uk_number_brand | 唯一 | number, brand_name | 联合唯一，关联安全库存表 |
| idx_brand_name | 普通 | brand_name | 按品牌筛选 |
| idx_frey_no | 普通 | frey_no | 按条码筛选 |
| idx_stat_date | 普通 | stat_date | 按统计日期筛选 |

## 三、关键设计点

- **(number, brand_name) 联合唯一键**：同一 OE 号存在多个品牌
- **完整自然月对齐**：annual_sales_1y 与 monthly_sales_json 的12个月键完全对齐
- **52周窗口**：周维度用于计算 σ_w，与月度统计窗口对齐（截止上月最后一天）
- **每日全量重写**：TRUNCATE + 批量 INSERT（见 [10_销量表生成流程](10_销量表生成流程.md)）
