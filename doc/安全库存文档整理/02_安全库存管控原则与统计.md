# 安全库存管控原则与统计

> 本文为 [01_安全库存算法与公式](01_安全库存算法与公式.md) 的续篇。

## 一、ABC 分类管控原则

- **分类管控**：基于 ABC 分类差异化设置 Z系数与覆盖天数
- **成本平衡**：高价值物料严控安全库存，低价值通用物料适度提高
- **动态更新**：安全库存值定期复盘更新
- **极值兜底**：设置上下限避免算法极值导致备货异常

## 二、数据统计周期

- 常规物料：取近12个完整自然月历史净销量
- 季节性物料：季节系数通过 `monthly_sales_json` 体现，范围限制 0.7~1.3
- 新物料（无历史数据）：积累数据后自动切换

## 三、销量标准差计算

基于近52周（完整自然周）各周净销量，使用总体标准差（ddof=0）：

```python
import numpy as np
week_matrix = df[WEEK_COLUMNS].to_numpy(dtype=float)
sales_std_dev_1y = np.round(np.std(week_matrix, axis=1, ddof=0), 2)
```

> 程序实现见 `build_oe_parts_sales_service.py` 的 `_derive_fields`，使用 pandas 向量化计算 52 周数据。

**为什么用周标准差而非月标准差**：安全库存公式 `SS = Z × σ_w × √(L/7)` 需要的是周销量标准差 σ_w，12个月的数据点不足以支撑稳定的周级标准差估计，52周数据点提供更稳健的统计估计。
