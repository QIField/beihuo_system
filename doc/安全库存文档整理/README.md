## 与代码一致性说明

- 产品标识字段名统一：`number`（OE号）、`pdname`（产品名称）、`frey_no`（条码），无字段映射层
- 退货关联表：已移除价格字段，唯一键 `uk_normal_refund(normal_order_items_id, refund_order_items_id)`
- Step2 匹配条件：`customer_id OR fullname`
- Z系数：A=1.5 / B=1.2 / C=0.8
- 标准差：基于52周数据（非12个月），使用总体标准差 ddof=0
- 销量表刷新：直接 TRUNCATE + batch_insert，无备份/防并发机制
