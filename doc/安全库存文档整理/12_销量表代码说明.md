# 销量表代码说明（oe_parts_sales）

> 代码实现：DB端聚合 + pandas派生 + 全量重写。
> 详细 SQL 见 [13_销量表SQL文档](13_销量表SQL文档.md)。

## 一、模块结构

| 模块 | 文件 |
|------|------|
| ORM 模型 | `app/models/orm_models/stock_safe_models/oe_parts_sales.py` |
| DAO | `app/dao/stock_safe_dao/build_oe_parts_sales.py` |
| 服务 | `app/services/stock_safe_service/build_oe_parts_sales_service.py` |

## 二、DAO 层方法

| 方法 | 用途 |
|------|------|
| `fetch_aggregated_sales(...)` | DB端聚合抽取：UNION ALL + GROUP BY + SUM CASE，输出 SKU 维度结果 |
| `truncate_table()` | 清空原表（TRUNCATE DDL） |
| `batch_insert(rows, batch_size=2000)` | 批量插入（executemany），含 weekly_sales_json |

## 三、服务层核心函数

```
run_sync() -> dict:
  1. 计算参数（stat_date, months, weekly_ranges）
  2. 阶段1: fetch_aggregated_sales（DB端聚合）
  3. 阶段2: _derive_fields（pandas向量化派生）
  4. 阶段3: truncate_table() + batch_insert()
  5. 返回结果统计
```

## 四、辅助函数

- `_last_12_months(stat_date)`：生成12个完整自然月键列表（从旧到新）
- `_last_52_weeks(stat_date_ts)`：生成52个周范围（从旧到新）
- `_derive_fields(rows, ...)`：pandas 向量化计算日均/月均/标准差/JSON

## 五、关键实现要点

1. **DB端聚合**：单次 SQL 完成合并+分组+条件聚合，避免读取明细到内存
2. **净销量**：第一部分取 quantity，第二部分取 processed_quantity（type=21/22 最新 match_count）
3. **时间维度**：统一取常规订单 create_date（秒级时间戳），SQL 内 FROM_UNIXTIME/DATE_FORMAT 转日/月/年键
4. **52周窗口**：周维度用于计算 σ_w（np.std ddof=0），12个月度列用于 monthly_sales_json
5. **全量重写**：TRUNCATE + batch_insert（2000条/批）
6. **无备份/防并发机制**：直接 TRUNCATE 后写入，异常时抛出上层处理
