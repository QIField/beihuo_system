# 安全库存算法与公式

> 公式依据：`app/services/stock_safe_service/stock_safe_compute_service.py`（以代码实现为准）
> 续篇：库存状态判定见 [18_库存状态判定](18_库存状态判定.md)

## 一、配置参数速查

### 1.1 ABC 分类参数

| 参数 | A类 | B类 | C类 |
|------|-----|-----|-----|
| Z系数（安全系数） | 1.5 | 1.2 | 0.8 |
| 订货周期（天） | 10 | 20 | 30 |
| 产品占比 | 20% | 60% | 20% |

- Z系数为自定义安全系数，A类高保护、C类低保护以控制成本
- 订货周期（Order Cycle）：两次订货之间的时间间隔，代码中称为 `cover`
- 零年销量产品强制归为 C 类

### 1.2 其他全局参数

| 参数 | 值 | 代码常量 |
|------|-----|---------|
| 补货周期 L | 1 天 | `LEAD_TIME = 1` |
| 季节系数范围 | 0.7 ~ 1.3 | `SEASON_MIN, SEASON_MAX` |
| 积压阈值 | 1.3 倍 | `OVERSTOCK_RATIO = 1.3` |

## 二、核心算法公式

### 2.1 基础安全库存

```
SS = Z × σ_w × √(L / 7)
基础安全库存 = Z系数 × 周销量标准差 × 根号(补货周期天数 ÷ 7)
```

| 参数 | 含义 | 说明 |
|------|------|------|
| Z | 安全系数 | A=1.5, B=1.2, C=0.8 |
| σ_w | 周销量标准差 | 基于近52周净销量总体标准差(ddof=0) |
| L | 补货周期 | 从下单到入库天数，当前1天 |

**逻辑**：独立时间段内需求波动遵循方差叠加。L天(L/7周)内需求标准差 = σ_w × √(L/7)。Z系数放大此标准差以覆盖补货期间超预期需求。

### 2.2 季节系数

```
SF = S_m / S_avg
季节系数 = 当月销量 / 全年平均月销量
```

| 参数 | 含义 | 说明 |
|------|------|------|
| S_m | 当月净销量 | 取最近一个完整月份 |
| S_avg | 月均销量 | 年总销量/12 |

结果钳制到 [0.7, 1.3] 范围，防止极端值扭曲安全库存。

### 2.3 调整后安全库存

```
SS_adj = SS × SF
调整后安全库存 = 基础安全库存 × 季节系数
```

旺季上调、淡季下调，使安全库存随季节波动动态变化。

### 2.4 库存下限（再订货点 ROP）

```
ROP = D_avg × L + SS_adj
库存下限 = 平均日销量 × 补货周期 + 安全库存
```

| 参数 | 含义 | 说明 |
|------|------|------|
| D_avg | 平均日销量 | 年总净销量/实际天数 |
| L | 补货周期 | 1天 |
| SS_adj | 调整后安全库存 | 缓冲应对需求波动 |

### 2.5 库存上限（目标库存）

```
Max = D_avg × (L + R) + SS_adj
库存上限 = 平均日销量 × (补货周期 + 订货周期) + 安全库存
```

| 参数 | 含义 | 说明 |
|------|------|------|
| R | 订货周期 | A=10天, B=20天, C=30天 |

### 2.6 可卖天数

```
DOS = Q_avail / D_avg
可卖天数 = 可用库存 / 平均日销量
```

除零保护：D_avg=0 时返回 0。
