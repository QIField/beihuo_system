# 销量计算逻辑（净销量）

> 销量表 `oe_parts_sales` 的净销量来源于 `sales_order_history` 与 `stock_safe_refund_ref`，按 (number, brand_name) 聚合。

## 一、净销量计算公式

```
某(number, brand_name)的净销量 =
    Σ quantity                   -- 第一部分：order_type_id=1，排除已退货订单
  + Σ processed_quantity         -- 第二部分：refund_ref type=21/22 最新 match_count
```

## 二、第一部分 — 无退货常规订单

- 取 `order_type_id=1`（常规订单）
- 排除已存在于 `stock_safe_refund_ref.normal_order_items_id` 且 type IN (11~33) 的订单
- 剩余订单按 `quantity` 计入净销量，时间维度取 `create_date`（秒级时间戳）

## 三、第二部分 — 部分退货净额

- 取 `type IN (21, 22)`（部分退货，processed_quantity > 0）
- 对同一 `normal_order_items_id`，取 `match_count = MAX(match_count)` 的最新记录
- `processed_quantity` 即为净销量（退货后剩余数量）
- 时间维度取 JOIN 的 `sales_order_history.create_date`

## 四、type 处理矩阵

| refund_ref type | 含义 | 净销量取值 |
|----------------|------|-----------|
| 11/12/13 | 完全退货（pq=0） | 0（已排除） |
| 21/22 | 部分退货（有剩余） | processed_quantity |
| 23/31/32/33 | 退货视角/超出 | 0（已排除） |
| 不在 refund_ref | 无退货 | quantity |

## 五、字段对应关系

产品标识字段三表统一，无字段映射层：`number`（OE号）、`brand_name`（品牌名）、`pdname`（产品名称）、`frey_no`（条码）。

## 六、聚合统计字段

| 字段 | 计算公式 | 时间范围 |
|------|---------|---------|
| annual_sales_1y | Σ 净销量 | 近12个完整自然月 |
| avg_daily_sales_1y | annual_sales_1y / 实际天数 | 近12个完整自然月 |
| avg_monthly_sales_1y | annual_sales_1y / 12 | 近12个完整自然月 |
| sales_this_year | Σ 净销量 | 当前自然年 |
| sales_last_year | Σ 净销量 | 上一完整自然年 |
| sales_std_dev_1y | np.std(week_1~52, ddof=0) | 近52周各周净销量 |
| monthly_sales_json | `{"YYYY-MM": 数量}` | 近12个完整自然月 |
| weekly_sales_json | `{"YYYY-MM-DD": 数量}` | 近52周 |
