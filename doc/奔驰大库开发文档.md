# 奔驰大库开发文档

## 1. 项目概述

### 1.1 项目简介
奔驰大库系统是一个汽车配件管理与查询系统，主要功能包括：
- 配件信息的查询、添加、编辑、删除
- 批量导入配件数据
- 配件数据的爬取与更新
- 收藏夹功能
- 价格计算与展示

### 1.2 技术栈
- **后端框架**: Flask
- **ORM**: SQLAlchemy
- **前端框架**: Layui
- **数据库**: MySQL

## 3. 数据模型

### 3.1 奔驰配件模型 (CarPartsLibraryBenz)

**文件路径**: `app/models/orm_models/car_parts_library_benz.py`

**表名**: `car_parts_library_benz`

**字段说明**:

| 字段名 | 类型 | 主键 | 说明 |
|--------|------|------|------|
| part_number | String(510) | 是 | 配件编号 |
| descriptions | String(510) | 否 | 英文描述 |
| description_cn | String(510) | 否 | 中文描述 |
| marketing_code | String(510) | 否 | 营销代码 |
| dealer_discount_group | String(510) | 否 | 经销商折扣组 |
| msrp | Float | 否 | 建议零售价 |
| dealer_fixed_nominal_margin | Float | 否 | 经销商固定名义利润 |
| wholesale_price | Float | 否 | 批发价格 |
| marketing_code_description | String(510) | 否 | 营销代码描述 |
| quantity_unit | String(510) | 否 | 数量单位 |
| sales_pack_size | String(510) | 否 | 销售包装规格 |
| weight | BigInteger | 否 | 重量 |
| length | String(510) | 否 | 长度 |
| width | String(510) | 否 | 宽度 |
| height | String(510) | 否 | 高度 |
| effective_date | String(510) | 否 | 生效日期 |
| data_source | String(100) | 否 | 数据来源 |
| l_model_zh | Text | 否 | 车型中文名 |
| brand | String(100) | 否 | 品牌 |
| category | String(100) | 否 | 分类 |
| ccc_mark | String(50) | 否 | CCC标识 |
| volume | DECIMAL(10,3) | 否 | 体积 |
| hazmat_code | String(50) | 否 | 危险货物代码 |
| origin_country | String(50) | 否 | 原产地 |
| shelf_life | String(100) | 否 | 存储期限 |
| is_hazmat | String(10) | 否 | 防盗标识/危险品 |
| purchase_price | DECIMAL(18,2) | 否 | 巴博瑞采购价 |
| part_nr_info_super_session | LONGTEXT | 否 | 零件替代关系信息(JSON) |
| created_at | DateTime | 否 | 创建时间 |
| updated_at | DateTime | 否 | 更新时间 |

**方法说明**:
- `to_dict()`: 将对象转换为字典
- `to_web_dict(tax_rate=1.13, discount_rate=0.83)`: 转换为前端使用的字典，包含计算后的价格

**价格计算公式**:
- 4S含税进价 = 批发价 × 税率
- 巴博瑞采购价 = 批发价 × 税率 × 折扣率

## 4. API接口

### 4.1 奔驰配件API (benz_parts_bp)

**文件路径**: `app/api/car_parts_library_api/benz_parts_api.py`

**路由前缀**: `/new/api/car-parts`

#### 4.1.1 获取配件列表
- **接口**: `GET /list`
- **参数**:
  - `page`: 页码（默认1）
  - `page_size`: 每页条数（默认20）
  - `part_number`: 配件编号筛选（可选）
- **返回**:
```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "status": true,
    "msg": "查询成功",
    "count": 100,
    "data": [...]
  }
}
```

#### 4.1.2 获取配件详情
- **接口**: `GET /detail`
- **参数**:
  - `part_number`: 配件编号
- **返回**:
```json
{
  "code": 200,
  "msg": "success",
  "data": {...}
}
```

#### 4.1.3 批量刷新数据
- **接口**: `POST /batch-refresh`
- **参数**:
```json
{
  "part_numbers": ["配件编号1", "配件编号2"]
}
```
- **返回**:
```json
{
  "code": 200,
  "msg": "刷新成功",
  "data": {
    "status": true,
    "msg": "数据刷新成功",
    "parts_count": 10,
    "stock_count": 5
  }
}
```

#### 4.1.4 添加配件
- **接口**: `POST /add`
- **参数**: 配件数据字典
- **返回**:
```json
{
  "code": 200,
  "msg": "添加成功",
  "data": null
}
```

#### 4.1.5 更新配件
- **接口**: `POST /update`
- **参数**: 包含 part_number 的配件数据字典
- **返回**:
```json
{
  "code": 200,
  "msg": "更新成功",
  "data": null
}
```

#### 4.1.6 删除配件
- **接口**: `POST /delete`
- **参数**:
```json
{
  "part_number": "配件编号"
}
```
- **返回**:
```json
{
  "code": 200,
  "msg": "删除成功",
  "data": null
}
```

#### 4.1.7 批量导入配件
- **接口**: `POST /import`
- **参数**: 表单数据，包含 file 字段
- **说明**: 插入更新模式，存在则更新，不存在则插入
- **返回**:
```json
{
  "code": 200,
  "msg": "导入成功",
  "data": {
    "total": 100,
    "success": 95,
    "failed": 5,
    "success_part_numbers": [...]
  }
}
```

#### 4.1.8 下载导入模板
- **接口**: `GET /template`
- **返回**: Excel文件

## 5. 服务层

### 5.1 奔驰配件服务

**文件路径**: `app/services/car_parts_library_service/car_parts_library_benz_service.py`

**核心方法**:

| 方法名 | 说明 |
|--------|------|
| `get_part_by_number(part_number)` | 根据配件编号获取详情 |
| `get_parts_list_page(page, page_size, part_number)` | 分页获取配件列表 |
| `data_refresh(part_numbers)` | 批量刷新数据 |
| `get_crmapp_compare_summary(oe_list, vehicle_brand, company)` | 从比价系统获取数据并更新 |
| `add_part(part_data)` | 添加配件 |
| `update_part(part_number, part_data)` | 更新配件 |
| `delete_part(part_number)` | 删除配件 |
| `import_parts(file_obj, filename)` | 批量导入配件 |
| `download_template()` | 下载导入模板 |

### 5.2 收藏服务

**文件路径**: `app/services/car_parts_library_service/car_parts_favorite_service.py`

**核心方法**:

| 方法名 | 说明 |
|--------|------|
| `add_to_favorites(user_id, part_numbers, category)` | 批量添加收藏 |
| `get_user_favorites(user_id, category, page, page_size)` | 获取用户收藏列表 |
| `remove_from_favorites(user_id, part_numbers)` | 批量删除收藏 |
| `get_user_favorite_categories(user_id)` | 获取用户收藏分类 |
| `batch_add_to_favorites(user_id, part_numbers, category)` | 批量添加收藏（优化版） |
| `move_to_main_category(user_id, part_numbers)` | 移动到主收藏 |
| `copy_to_main_category(user_id, part_numbers)` | 复制到主收藏 |
| `clear_category_favorites(user_id, category)` | 清空分类收藏 |

## 10. 常见问题

### 10.1 数据刷新失败
- 检查奔驰大库配置是否正确
- 检查Cookie是否有效
- 检查网络连接

### 10.2 导入失败
- 检查文件格式是否正确
- 检查文件大小是否超过限制
- 查看错误详情中的具体原因

### 10.3 收藏功能无法使用
- 确保用户已登录
- 检查数据库连接是否正常
