# 缓存管理模块使用方法

> 对应文件：`app/core/cache_utils.py`
>
> 用途：在进程内存中做缓存（类似 Redis 的基础功能），无需安装外部服务。

---

## 1. 两种使用方式

| 方式 | 适用场景 | 关键入口 |
| --- | --- | --- |
| **函数装饰器**（推荐） | 给一个函数/方法加速，避免重复计算或重复查询数据库 | `@cache_function_result(ttl=300)` |
| **手动 key 管理** | 需要精细控制（比如写操作后手动失效、key 自己定义） | `get_default_cache()` + `.set/.get/.delete` |

---

## 2. 方式一：装饰器（最常用）

```python
from app.core.cache_utils import cache_function_result

# 加了这一行，相同参数第二次调用会直接返回缓存结果
@cache_function_result(ttl=300)        # 缓存 5 分钟
def query_company_report(company_id: int):
    # 这里可以是数据库查询、网络请求、慢计算等
    rows = db.execute(
        "SELECT ... WHERE company_id = ?", company_id
    ).fetchall()
    return rows

# 使用
report1 = query_company_report(1001)   # 真的执行函数
report2 = query_company_report(1001)   # 命中缓存，直接返回
report3 = query_company_report(1002)   # 参数不同，重新执行
```

### 参数说明

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `ttl` | `None`（使用 Cache 实例的默认 TTL） | 缓存多少秒 |
| `cache_obj` | `None`（使用应用级默认缓存） | 传入自己的 `Cache` 实例 |
| `skip_none` | `True` | 函数返回 `None` 时**不缓存**，避免污染 |

---

## 3. 方式二：手动 key 管理

```python
from app.core.cache_utils import get_default_cache

cache = get_default_cache()   # 整个应用共用的缓存实例

# 1) 读取，不存在则计算并写入
KEY = f"product:stock:{product_id}"
stock = cache.get(KEY)
if stock is None:
    stock = query_stock_from_db(product_id)
    cache.set(KEY, stock, ttl=30)   # 30 秒过期

# 2) 数据有更新，主动失效缓存
def update_stock(product_id, new_stock):
    db.update_stock(product_id, new_stock)
    cache.delete(f"product:stock:{product_id}")
```

### 常用 API

```python
cache.set(key, value, ttl=300)       # 写入（ttl 单位秒，可省略使用默认）
cache.get(key, default=None)         # 读取，未命中/已过期返回 default
cache.delete(key)                    # 删除
cache.exists(key)                    # 是否存在且未过期
cache.expire(key, 120)               # 给已有键设置过期时间（秒）
cache.ttl(key)                       # 剩余秒数 / -1永不过期 / -2不存在
cache.keys("user:*")                 # 支持 * 通配符，返回键列表
cache.clear()                        # 清空全部
len(cache)                           # 当前键数量
```

---

## 4. TTL 建议参考

| 场景 | 建议 TTL |
| --- | --- |
| 实时数据 / 库存 | 30 ~ 60 秒 |
| 报表 / 统计 | 300 ~ 1800 秒 |
| 配置 / 字典表 | 3600 秒或永不过期 |

---

## 5. 常见问题

1. **装饰器的缓存 key 是怎么生成的？**
   根据函数名 + 参数自动生成。传给被装饰函数的参数用基础类型（int/str/dict/list/tuple）即可，不用担心。

2. **多线程场景下要不要加锁？**
   `get_default_cache()` 默认已经是 `thread_safe=True`，在 Flask + 定时任务场景下直接用就行。

3. **数据更新后缓存怎么办？**
   参考"方式二"，写操作后调用 `cache.delete(KEY)` 让缓存失效，下次读时重新生成。

4. **与 Redis 的区别？**
   本模块是**进程内内存缓存**，单进程使用最方便；如果部署多 worker / 需要持久化 / 跨进程共享，请改用 Redis。
