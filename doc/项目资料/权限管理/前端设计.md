# 权限管理系统前端页面设计方案

## 一、技术栈与架构

**前端框架**：Layui（与项目现有页面保持一致）
**路由方式**：Flask Blueprint + URL 前缀
**页面结构**：侧边导航 + 内容区 + 弹窗表单

***

## 二、页面结构设计（共 5 个页面）

```
templates/
└── permission_manager_web/
    ├── permission_manager_main_web.html     # 主页面（导航容器）
    ├── permission_list.html                  # 权限列表
    ├── role_management.html                  # 角色管理
    ├── user_role_assignment.html             # 用户角色分配
    └── my_permissions.html                   # 我的权限（可选）
```

```
app/routes/
└── permission_manager_web.py                 # 路由蓝图
```

***

## 三、各页面详细设计

### 页面 1：权限管理主页面（导航容器）

**文件**：`permission_manager_main_web.html`
**访问路径**：`/permission_manager`

**布局**（参考 `customer_quota_manager_main_web.html`）：

- 左侧导航栏：
  - 权限管理（权限列表）
  - 角色管理（角色列表）
  - 用户角色分配
  - 我的权限（可选）
- 右侧内容区：通过 hash 路由动态加载子页面

**导航项与 URL 映射**：

| 导航项    | Hash 路由                  | 对应页面                        |
| ------ | ------------------------ | --------------------------- |
| 权限管理   | `#/permission_list`      | permission\_list.html       |
| 角色管理   | `#/role_management`      | role\_management.html       |
| 用户角色分配 | `#/user_role_assignment` | user\_role\_assignment.html |
| 我的权限   | `#/my_permissions`       | my\_permissions.html        |

***

### 页面 2：权限列表页

**文件**：`permission_list.html`
**功能**：权限的增删改查

**页面元素**：

```
┌────────────────────────────────────────────────────┐
│ 权限管理（标题栏 + 搜索 + 新增按钮）               │
├────────────────────────────────────────────────────┤
│ 🔍 搜索框（按权限名称/编码）  [搜索] [重置]        │
│ 筛选：类型 [全部▼|模块权限|操作权限]  [+ 新增权限] │
├────────────────────────────────────────────────────┤
│ 数据表格（分页）                                    │
│ ┌────┬──────────┬──────────┬────────┬────┬──────┐ │
│ │ ID │ 权限名称 │ 权限编码 │ 类型   │ 状态│ 操作 │ │
│ ├────┼──────────┼──────────┼────────┼────┼──────┤ │
│ │ 1  │ 删除购物车│ cart:del │ 操作权限│ 启用│ 编辑 │ │
│ │ 2  │ 查看报表 │ report:v │ 操作权限│ 启用│ 编辑 │ │
│ └────┴──────────┴──────────┴────────┴────┴──────┘ │
└────────────────────────────────────────────────────┘
```

**弹窗：新增/编辑权限**：

| 字段   | 类型  | 必填 | 说明                  |
| ---- | --- | -- | ------------------- |
| 权限名称 | 文本框 | ✅  | 如"删除购物车"            |
| 权限编码 | 文本框 | ✅  | 如"cart:delete"，全局唯一 |
| 类型   | 下拉框 | ✅  | 模块权限 / 操作权限         |
| 父权限  | 下拉框 | ☐  | 仅操作权限可选所属模块         |
| 描述   | 文本域 | ☐  | 权限说明                |
| 状态   | 开关  | ✅  | 启用/禁用               |

**后端 API 需求**（对应后端已有的 `PermissionManagementService`）：

- `GET /api/permission/list?page=1&page_size=20&keyword=&type=` — 分页列表
- `GET /api/permission/{id}` — 详情
- `POST /api/permission` — 新增
- `PUT /api/permission/{id}` — 更新
- `DELETE /api/permission/{id}` — 删除
- `GET /api/permission/all` — 全部权限（下拉选择用）

### 页面 3：角色管理页

**文件**：`role_management.html`
**功能**：角色的增删改查 + 角色权限分配

**布局**：左侧角色列表 + 右侧角色详情/权限分配

```
┌────────────────────────────────────────────────────────────┐
│ 角色管理                                                     │
├──────────────┬─────────────────────────────────────────────┤
│ [+ 新增角色]  │  角色详情                                    │
│ ┌────────────┐│  ┌─────────────────────────────────────┐   │
│ │ 超级管理员  ││  │ 角色名称：[超级管理员         ]     │   │
│ │ 业务人员    ││  │ 角色编码：[super_admin          ]     │   │
│ │ 只读用户    ││  │ 描述：    [_____________________]      │   │
│ │ ...         ││  │ 父角色：[▼选择...]                    │   │
│ └────────────┘│  │ 状态：    [●启用 ○禁用]                │   │
│              │  └─────────────────────────────────────┘   │
│              │                                             │
│              │  已分配权限（按模块分组，树形结构）           │
│              │  ☑ 购物车                                    │
│              │     ☑ cart:delete                           │
│              │     ☑ cart:view                             │
│              │  ☑ 报表                                      │
│              │     ☑ report:view                           │
│              │  [保存权限分配]                              │
└──────────────┴─────────────────────────────────────────────┘
```

**弹窗：新增/编辑角色**：

| 字段   | 类型  | 必填        |
| ---- | --- | --------- |
| 角色名称 | 文本框 | ✅         |
| 角色编码 | 文本框 | ✅（唯一）     |
| 描述   | 文本域 | ☐         |
| 父角色  | 下拉框 | ☐（用于角色继承） |
| 状态   | 开关  | ✅         |

**权限分配区**（树形复选框）：

- 按"模块权限"分组
- 每个模块下挂"操作权限"
- 支持全选/反选模块
- 保存时提交权限 ID 数组

**后端 API 需求**（对应 `RoleManagementService`）：

- `GET /api/role/list?page=1&page_size=20&keyword=`
- `GET /api/role/{id}`
- `POST /api/role`
- `PUT /api/role/{id}`
- `DELETE /api/role/{id}`
- `GET /api/role/{id}/permissions` — 获取角色分配的权限
- `PUT /api/role/{id}/permissions` — 保存权限分配
- `GET /api/role/all` — 全部角色（下拉选择用）

### 页面 4：用户角色分配页

**文件**：`user_role_assignment.html`
**功能**：为用户分配/取消角色

**布局**：左侧用户列表 + 右侧角色分配面板

```
┌────────────────────────────────────────────────────────────┐
│ 用户角色分配                                                 │
├──────────────┬─────────────────────────────────────────────┤
│ 🔍 用户搜索   │  当前用户：张三（user_1001）                  │
│ 用户名/编码   │                                             │
│ [搜索]        │  可用角色列表（带复选框）                      │
│              │  ┌─────────────────────────────────┐       │
│ 用户名列表    │  │ ☑ 超级管理员   描述：全功能权限     │       │
│ ┌────────────┐│  │ ☑ 业务人员    描述：可操作业务功能   │       │
│ │ ★ 张三     ││  │ ☑ 只读用户    描述：仅查看数据       │       │
│ │   李四     ││  │ ...                               │       │
│ │   王五     ││  └─────────────────────────────────┘       │
│ └────────────┘│                                             │
│              │  [保存分配] [重置]                           │
└──────────────┴─────────────────────────────────────────────┘
```

**交互**：

- 点击左侧用户 → 右侧显示该用户已分配角色（勾选状态）
- 勾选/取消勾选 → 点击"保存分配"提交

**后端 API 需求**（对应 `UserRoleManagementService`）：

- `GET /api/user/list?page=1&page_size=20&keyword=` — 用户列表
- `GET /api/user/{id}/roles` — 获取用户已分配角色
- `PUT /api/user/{id}/roles` — 批量分配角色（传 role\_ids）
- `GET /api/role/{id}/users` — （可选）查看某角色下的用户

## 五、开发建议

1. **先做哪页**：建议按顺序开发 权限列表 → 角色管理 → 用户角色分配 → 我的权限
2. **权限控制**：每个管理页面本身也要加权限保护（用户必须有对应权限才能访问）
3. **UI 风格**：保持和现有 `customer_quota_manager_main_web.html` / `beihuo_system_config_web.html` 一致的 Layui 风格
4. **表格组件**：用 Layui 的 `table` 组件 + 分页
5. **弹窗表单**：用 Layui 的 `layer.open` + `form` 组件
6. **树形权限选择**：可使用 Layui 的 `tree` 组件，或手写嵌套的 `div + checkbox`
